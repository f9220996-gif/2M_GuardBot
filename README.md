# ربات مدیریت گروه تلگرام

## نصب

```bash
pip install -r requirements.txt
```

## تنظیمات (اجباری قبل از اجرا)

فایل `config.py` را باز کنید و این دو مورد را پر کنید:

```python
BOT_TOKEN = "توکن ربات از @BotFather"
CREATOR_ID = 123456789   # آیدی عددی خودتان (از @userinfobot بگیرید)
```

یا به‌جای ویرایش فایل، متغیر محیطی ست کنید:

```bash
export BOT_TOKEN="توکن_شما"
export CREATOR_ID="123456789"
```

## اجرا

```bash
python main.py
```

## نکات مهم برای فعال شدن کامل قابلیت‌ها

1. ربات را به گروه اضافه کنید و **ادمین کامل** کنید (حتماً دسترسی «حذف پیام‌ها»،
   «محدود کردن اعضا» و «مسدود کردن کاربران» را فعال کنید — بدون این‌ها دستورات
   قفل/سکوت/بن کار نمی‌کنند).
2. اولین کسی که ربات را وارد گروه می‌کند به‌عنوان «مالک گروه» (از دید ربات) ثبت
   می‌شود و در پی‌وی ربات، از پنل مدیریت گروه‌های خودش می‌تواند آن گروه را ببیند.
3. سازنده ربات (CREATOR_ID) روی همه‌ی گروه‌ها و همه‌ی کاربران (حتی مدیران و
   مالکان گروه‌ها) دسترسی کامل دارد.

## دستورات داخل گروه (فارسی، بدون اسلش)

| دستور | توضیح |
|---|---|
| `خاموشی` یا `خاموشی 5h` | قفل کردن گروه، با یا بدون تایمر خودکار (h ساعت / m دقیقه / s ثانیه) |
| `روشن` | باز کردن فوری گروه حتی اگر تایمر فعال باشد |
| `سکوت 30m` (ریپلای) | سکوت کاربر برای مدت مشخص |
| `آزاد کن` (ریپلای) | برداشتن سکوت |
| `بن کن دلیل` (ریپلای) | بن کامل کاربر |
| `پاک` (ریپلای) | حذف پیام |
| `گیف بن` (ریپلای روی گیف) | افزودن گیف به لیست سیاه |
| `استیکر بن` (ریپلای روی استیکر) | افزودن استیکر به لیست سیاه |
| `تاس` | پرتاب تاس |
| `شیر_یا_خط` | بازی شیر یا خط |
| `سنگ_کاغذ_قیچی سنگ` | بازی سنگ‌کاغذقیچی با ربات |
| `حدس_عدد` سپس `حدس 7` | بازی حدس عدد ۱ تا ۱۰ |

## سیستم اخطار خودکار (فحش‌دهی)

اخطار ۱ → اخطار ۲ → اخطار ۳ → سکوت ۵ دقیقه (بار اول) → سکوت ۱۰ دقیقه (بار دوم) → بن کامل (بار سوم).
لیست کلمات ممنوعه پیش‌فرض در `config.py` (`DEFAULT_BAD_WORDS`) قابل ویرایش است؛ همچنین
می‌توانید کلمه جدید به دیتابیس (جدول `bad_words`) اضافه کنید.

## پنل‌ها (در پی‌وی ربات با /start)

- **⚙️ پنل مدیریت گروه‌های من**: لیست گروه‌هایی که این کاربر ربات را اضافه کرده؛
  برای هر گروه می‌توان قفل/باز کردن سریع، روشن/خاموش کردن ربات فقط برای آن گروه،
  و دیدن لیست بن‌شده‌ها / سکوت‌خورده‌ها / اخطارگرفته‌ها (با دلیل) را انجام داد.
- **👑 پنل ویژه سازنده** (فقط برای CREATOR_ID دیده می‌شود): خاموش/روشن کردن کامل
  ربات در همه‌جا + تنظیم متن دلخواه پیام خاموشی. وقتی خاموش است، ربات در هیچ
  گروهی پیام نمی‌دهد و فقط در پی‌وی به هرکسی پیام «در حال تعمیرات» (یا متن دلخواه
  شما) را می‌فرستد.

## نکاتی که خودتان باید تکمیل کنید

- **استیکرهای اخطار**: در کد جایی برای `sticker_file_id` و `gif_file_id` هر سطح
  اخطار در دیتابیس (جدول `warning_texts`) در نظر گرفته شده، اما چون انتخاب استیکر
  سلیقه‌ای است، خودتان باید با ریپلای روی استیکر دلخواه، `file_id` آن را بگیرید
  (با یک دستور ساده تست) و در دیتابیس ست کنید. در صورت خواستن، یک دستور پنلی
  برای این کار هم می‌توانم اضافه کنم.
- **دکمه Deep Link افزودن ربات**: در `handlers/start.py` پارامتر `admin=...` در
  لینک افزودن به گروه گذاشته شده تا هنگام افزودن، تلگرام خودش دسترسی‌های لازم
  را پیشنهاد بدهد؛ اگر می‌خواهید دسترسی‌های دیگری هم اضافه/کم شود، همان‌جا قابل
  ویرایش است.
